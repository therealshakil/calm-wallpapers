# Spec ideas — calm-wallpapers

*A parking place for rough, half-formed spec thoughts. Nothing here is in development. Each is a seed,
set down so it's safe, not lost — to be promoted into a numbered spec later, when there's margin.*

---

## 🌱 More themes, after Peanuts-poetry
The prompt ladder's Layer B (theme) is swappable. The first theme is Peanuts + poetry; later ones might
be a single quiet object, a lone landscape line, weather. Each new theme is a small addition to the
vocabulary, not a new process — promote one only when the first theme's set feels complete.

- Seed only — not in development.

## 🌱 A hand-run export helper
If exporting one keeper to three device sizes + tags by hand proves tedious, a tiny local helper could
stamp the sizes. It would need its own spec and Constitution Check (a script that *runs* is a different
thing from a prompt climbed by hand). Resist until the tedium is real.

- Seed only — not in development.
